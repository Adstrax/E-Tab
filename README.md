# E-Tab

Windows 11 File Explorer 增强工具，基于 [w4po/ExplorerTabUtility](https://github.com/w4po/ExplorerTabUtility) 精简而来。

本版本只保留一个功能：**文件夹从新标签页打开**。

## 功能

- 新打开的 File Explorer 窗口自动转为已有窗口中的标签页
- 路径已打开时切换到现有标签，避免重复标签
- 保留“在文件夹中显示”等操作传入的选中项
- 轻量原生系统托盘菜单（开机自启开关与退出），无 WPF/毛玻璃依赖，常驻内存更低
- 不包含热键、复制标签、恢复关闭标签、标签搜索、更新检查、窗口快照等功能

## 环境要求

- Windows 11 22H2（Build 22621）或更高版本
- File Explorer 标签页功能已启用
- 构建需要 .NET 10 SDK

## 构建

```powershell
dotnet build -c Release
```

## 版本规则

当前版本：`5.0.0`（基于 .NET 10，界面为英文）

## 变更记录
### v5.0.0

- 新标签检测改为事件驱动（WinEvent）：由轮询即时感知新标签，转化更快、等待期 CPU 更低（保留低频轮询兜底，避免极端情况下漏检）。
- 转换等待期降低 Shell 枚举频率（5ms 密集轮询改为 20–40ms 退避 + 事件驱动），减少 COM 往返与分配开销。
- 缩短地址栏快路径回车后的固定停顿，普通文件夹打开转化更快。
- 常驻进程空闲内存进一步平稳，长期运行更省。

### v4.0.0

- 整体改为 WinForms 架构，移除 WPF 界面与 Acrylic 毛玻璃/圆角样式，只保留“文件夹转新标签”核心功能。
- 移除更新检查与自更新整套（Check for updates、下载/安装进度、自更新替换）。
- 托盘菜单简化为原生菜单（状态头、开机自启开关、退出），托盘图标直接使用应用图标。
- 内存占用显著降低：常驻（空闲）工作集从数十 MB 降到约 13 MB。
- 新增空闲期 GC 回收与工作集修剪，长期运行内存保持平稳。
- 启用 InvariantGlobalization 与工作站 GC，降低运行时基线与启动开销。

### v3.7.7

- 修复地址栏快路径导航后地址栏停留在输入状态的问题：导航确认后自动发送 Esc 退出地址栏编辑模式，焦点回到文件列表，不再显示“输入中”的样式。

### v3.7.6

- 托盘图标小尺寸（16/24/32px）改用像素级硬边绘制的双文件夹标记：保留方案 7 的双文件夹语义，但图形填满画布、边缘不再抗锯齿发虚，在 200% 缩放（32px）下清晰锐利；48px 及以上仍为原 MergeFolders 设计。

### v3.7.5

- 托盘图标恢复为你选定的 MergeFolders 方案（双文件夹交叠 + 绿色状态点），所有尺寸统一使用该设计；此前小尺寸临时换成的“蓝底白文件夹”简化版已移除。

### v3.7.4

- 修复更新后重启卡死/转圈：更新器重启应用时不再把自更新环境变量传给新进程（此前会导致新进程误以为还在自更新模式、反复重启自己，表现为安装很快但重启很慢、鼠标一直转圈）。

### v3.7.3

- 托盘图标彻底修复：运行时直接解析 ICO 并按照系统 DPI 精确选取对应帧（不再依赖可能选错帧的 Icon 缩放），16/24/32px 使用“蓝底 + 白色文件夹”紧凑画法保证饱满清晰；48px 及以上仍为 MergeFolders 双文件夹设计。

### v3.7.2

- 更新交互改进：发现新版本时弹出“立即更新 / 暂不更新”确认窗口；下载时显示带进度条和取消按钮的进度窗口；失败时弹窗提示并给出日志路径。
- 更新下载自动读取 Windows 系统代理设置，修复代理环境下点击更新后一直转圈、无响应的问题。
- 托盘图标按系统实际托盘尺寸选取对应 ICO 帧（不再强制缩放到 32px），小尺寸图形放大填满画布，修复图标偏小、模糊的问题。

### v3.7.1

- 全新应用图标：双文件夹交叠（MergeFolders）设计，无底色、蓝白对比 + 绿色状态点，程序化矢量绘制并生成 16–256 多分辨率 ICO 与 32px 托盘/菜单图标。
- 修复托盘菜单在“下载更新”按钮隐藏时 Exit 下方出现大块空白的问题：菜单窗口高度改为内容自适应。

### v3.7.0

- 新增更新检查：托盘菜单 “Check for updates” 手动检查 GitHub Release，发现新版本时托盘气泡提示，点击即可自动下载、替换 exe 并重启，无需手动下载更新包。
- 检查失败会气泡提示原因，也可在日志中查看详情。
- 更新替换采用“自更新”模式：先把当前 exe 复制为更新器再退出，由更新器等待主进程退出后替换文件并重启，避免运行时覆盖正在执行的 exe；新版本启动时会清理更新残留并提示已更新。

### v3.6.0

- 空闲 CPU 大幅下降：移除每 500ms 的全量 explorer 进程扫描，改为直接监听主 explorer 进程退出事件，仅保留 1s 一次的廉价存活检查兜底。
- 空闲轮询不再每次枚举全部 ShellWindows：仅在检测到新窗口或每 5 秒执行一次完整快照，其余轮询只做轻量顶层窗口扫描。
- 文件夹转标签页全程移出 UI 线程：转换中的 COM 查询、导航与按键模拟不再阻塞 WinEvent 钩子投递，连续打开文件夹时捕获更及时。
- 新标签项查找增加窗口句柄预过滤，等待期不再对每个 Shell 窗口做 COM QueryService；同时清理转换路径上的多余列表分配。
- 两个 STA 线程命名区分（Shell poll STA / Conversion STA），便于日志诊断。

### v3.5.0

- 新导航快路径：新标签创建后直接驱动 Explorer 地址栏（Ctrl+L → 路径 → 回车），不再等待 Shell 项注册才导航，文件夹更早显示在标签页中；失败自动回退旧路径。

### v3.4.0

- 托盘菜单图标改用 Windows 11 原生 Segoe Fluent Icons 字体字形（开机自启、退出），矢量渲染任意尺寸清晰，随主题自动变色，无需图片资源。

### v3.3.0

- 进一步优化“文件夹转标签页”速度：转换使用独立 STA 线程，不再与周期轮询争抢单线程，转换等待与轮询可并行。
- 图标升级为 Windows 11 Fluent Design 风格：圆角方块底 + 白色文件夹 + 绿色状态点，小尺寸单独优化保持托盘清晰。
- 转换日志细化到阶段耗时（查找/建标签/等标签项/导航），便于持续诊断。

### v3.2.0

- 优化“文件夹转标签页”速度：转换锁只覆盖标签创建环节，连续打开多个文件夹时等待与导航可以并行；标签项轮询改为自适应退避，降低等待期开销。
- 新增转换耗时日志，便于持续诊断各环节耗时。

### v3.1.0

- 托盘菜单项加入 Win11 风格图标（开机自启、退出），并随亮色/暗色主题自动切换颜色。
- 优化菜单打开速度：菜单窗口改为常驻复用并预创建，不再每次右键重新初始化。

### v3.0.0

- 全新应用图标：Win11 风格渐变文件夹 + 绿色状态点，程序化矢量绘制并生成 16–256 多分辨率 ICO，托盘与应用内显示更锐利。

### v2.3.0

- 移除设置窗口：开机自启开关已在一级托盘菜单，设置窗口内的重复项与整窗一并删除，托盘菜单精简为状态、自启动开关与退出。

### v2.2.0

- 托盘菜单改为非分层窗口 + WCA Acrylic + DWM 圆角：毛玻璃与内容一起圆角，外圈不再露出直角边，背景更通透，观感对齐 Win11 右键菜单。

### v2.1.0

- 托盘菜单一级加入 “Start with Windows” 开关，无需再进入设置窗口即可切换开机自启。

### v2.0.0

- 发布包改为 .NET 单文件发布：解压后只有一个 `E-Tab.exe`，配合 `README.txt` 使用说明，下载即用。
- 新增一键打包脚本 `pack.ps1`，自动执行发布并产出扁平结构的发布包。

### v1.5.2

- 界面适配 Windows 11 原生效果：设置窗口与托盘菜单均启用 Acrylic 毛玻璃背景（与 TranslucentTB 同款 `SetWindowCompositionAttribute` 方案）、圆角与阴影，观感对齐 Win11 系统托盘。
- 支持跟随系统亮色/暗色模式自动切换配色与毛玻璃着色，无需重启即时生效。
- 设置窗口关闭按钮增加悬停/按下反馈。

### v1.5.0

- 优化“文件夹转为新标签页”的流程：等待新标签注册时不再做全量 Shell 快照，改用轻量查找并加快轮询，减少转换过程中短暂出现的 Home 界面并降低打开耗时。

### v1.4.0

- 改为自适应轮询：有新窗口活动时快速轮询（200ms），空闲时降到 1s，进一步降低常驻 CPU 占用。
- 修正托盘菜单在多显示器、混合 DPI 环境下的定位（按光标所在显示器计算缩放）。
- 新增轻量文件日志，写入 `%LOCALAPPDATA%\E-Tab\logs\E-Tab.log`，便于排查。
- 清理冗余代码（去掉无意义的 `Reverse()`、未使用的方法）。

### v1.3.1

- 修复首次启动时把已经存在的文件管理器窗口强行合并成标签页的问题：初始快照现在只记录现有窗口，不再主动合并，避免首次打开时窗口闪现、首次关闭时出现错乱窗口。

### v1.3.0

- 修复 WinEvent 钩子因注册在无消息循环的 STA 线程上而从未触发的问题，新窗口现在可被即时捕获，打开标签页延迟明显降低。
- 修复关闭文件管理器后可能再次弹出一个错乱窗口的问题：没有可合并的可见窗口时改为还原源窗口，而不是新建窗口。
- 退出改为优雅关闭，托盘图标、WinEvent 钩子、COM 对象和单实例互斥量可被正常释放。
- 修复轮询标志的竞态，并释放遗漏的注册表键和进程句柄。

每次增加新功能时，需要同时：

1. 修改 `E-Tab/E-Tab.csproj` 中的 `<Version>`（并同步 `AssemblyVersion`、`FileVersion`）
2. 更新本文件的“当前版本”
3. 提交 Git 并打上对应版本号的 tag，例如 `v1.0.0`
