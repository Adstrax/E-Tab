# E-Tab

Windows 11 File Explorer 增强工具，基于 [w4po/ExplorerTabUtility](https://github.com/w4po/ExplorerTabUtility) 精简而来。

本版本只保留一个功能：**文件夹从新标签页打开**。

## 功能

- 新打开的 File Explorer 窗口自动转为已有窗口中的标签页
- 路径已打开时切换到现有标签，避免重复标签
- 保留“在文件夹中显示”等操作传入的选中项
- Windows 11 风格系统托盘菜单，右键可打开设置或退出
- 设置窗口支持开机自动启动开关
- 不包含热键、复制标签、恢复关闭标签、标签搜索、窗口快照等功能

## 环境要求

- Windows 11 22H2（Build 22621）或更高版本
- File Explorer 标签页功能已启用
- 构建需要 .NET 10 SDK

## 构建

```powershell
dotnet build -c Release
```

## 版本规则

当前版本：`3.2.0`（基于 .NET 10，界面为英文）

## 变更记录

### v3.2.0

- 优化“文件夹转标签页”速度：转换锁只覆盖标签创建环节，连续打开多个文件夹时等待与导航可以并行；标签项轮询改为自适应退避，降低等待期开销。
- 新增转换耗时日志，便于持续诊断各环节耗时。

### v3.1.0

- 托盘菜单项加入 Win11 风格图标（开机自启、退出），并随亮色/暗色主题自动切换颜色。
- 优化菜单打开速度：菜单窗口改为常驻复用并预创建，不再每次右键重新初始化。

### v3.0.0

- 全新应用图标：Win11 风格渐变文件夹 + 绿色状态点，程序化矢量绘制并生成 16–256 多分辨率 ICO，托盘与应用内显示更锐利。

### v2.3.0

- 移除设置窗口：开机自启开关已在一级托盘菜单，设置窗口内的重复项与整窗一并删除，托盘菜单精简为状态、自启动开关与退出。

### v2.2.0

- 托盘菜单改为非分层窗口 + WCA Acrylic + DWM 圆角：毛玻璃与内容一起圆角，外圈不再露出直角边，背景更通透，观感对齐 Win11 右键菜单。

### v2.1.0

- 托盘菜单一级加入 “Start with Windows” 开关，无需再进入设置窗口即可切换开机自启。

### v2.0.0

- 发布包改为 .NET 单文件发布：解压后只有一个 `E-Tab.exe`，配合 `README.txt` 使用说明，下载即用。
- 新增一键打包脚本 `pack.ps1`，自动执行发布并产出扁平结构的发布包。

### v1.5.2

- 界面适配 Windows 11 原生效果：设置窗口与托盘菜单均启用 Acrylic 毛玻璃背景（与 TranslucentTB 同款 `SetWindowCompositionAttribute` 方案）、圆角与阴影，观感对齐 Win11 系统托盘。
- 支持跟随系统亮色/暗色模式自动切换配色与毛玻璃着色，无需重启即时生效。
- 设置窗口关闭按钮增加悬停/按下反馈。

### v1.5.0

- 优化“文件夹转为新标签页”的流程：等待新标签注册时不再做全量 Shell 快照，改用轻量查找并加快轮询，减少转换过程中短暂出现的 Home 界面并降低打开耗时。

### v1.4.0

- 改为自适应轮询：有新窗口活动时快速轮询（200ms），空闲时降到 1s，进一步降低常驻 CPU 占用。
- 修正托盘菜单在多显示器、混合 DPI 环境下的定位（按光标所在显示器计算缩放）。
- 新增轻量文件日志，写入 `%LOCALAPPDATA%\E-Tab\logs\E-Tab.log`，便于排查。
- 清理冗余代码（去掉无意义的 `Reverse()`、未使用的方法）。

### v1.3.1

- 修复首次启动时把已经存在的文件管理器窗口强行合并成标签页的问题：初始快照现在只记录现有窗口，不再主动合并，避免首次打开时窗口闪现、首次关闭时出现错乱窗口。

### v1.3.0

- 修复 WinEvent 钩子因注册在无消息循环的 STA 线程上而从未触发的问题，新窗口现在可被即时捕获，打开标签页延迟明显降低。
- 修复关闭文件管理器后可能再次弹出一个错乱窗口的问题：没有可合并的可见窗口时改为还原源窗口，而不是新建窗口。
- 退出改为优雅关闭，托盘图标、WinEvent 钩子、COM 对象和单实例互斥量可被正常释放。
- 修复轮询标志的竞态，并释放遗漏的注册表键和进程句柄。

每次增加新功能时，需要同时：

1. 修改 `E-Tab/E-Tab.csproj` 中的 `<Version>`（并同步 `AssemblyVersion`、`FileVersion`）
2. 更新本文件的“当前版本”
3. 提交 Git 并打上对应版本号的 tag，例如 `v1.0.0`
