E-Tab v7.0.0 使用说明
=====================

E-Tab 是 Windows 11 文件资源管理器增强工具：新打开的文件夹窗口会自动合并成已有窗口中的标签页。

快速开始
--------
1. 双击运行 E-Tab.exe（绿色软件，无需安装；本包为单文件版）。
2. 程序启动后驻留在系统托盘（屏幕右下角），并开始自动工作。
3. 右键托盘图标可以：
   * Auto-merge new windows —— 是否自动把新窗口合并成标签页（默认开启）
   * Merge all windows (Ctrl+Shift+E) —— 把当前所有窗口一次性合并成一个窗口的标签页
   * Start with Windows —— 开机自启
   * Exit —— 退出程序

常见问题
--------
* 双击没有反应？请先安装 .NET 10 Desktop Runtime：
  https://dotnet.microsoft.com/download/dotnet/10.0
* 如何完全退出？右键托盘图标 → Exit。
* 想让某个文件夹单独开一个窗口？按住 Ctrl+Shift 再双击它。
