E-Tab v3.7.3 使用说明
=====================

E-Tab 是 Windows 11 文件资源管理器增强工具：新打开的文件夹窗口会自动合并成已有窗口中的标签页。

快速开始
--------
1. 双击运行 E-Tab.exe（绿色软件，无需安装；本包为单文件版）。
2. 程序启动后驻留在系统托盘（屏幕右下角），并开始自动工作。
3. 右键托盘图标可切换 “Start with Windows” 开机自启、检查更新或退出程序。

检查更新
--------
* 右键托盘图标 → Check for updates 手动检查 GitHub Release，发现新版本时托盘会弹出提示。
* 点击气泡提示（或托盘菜单中的 “Download & install” 入口）即可自动下载并替换为新版本，无需手动下载更新包。
* 检查失败会弹出提示，也可在日志中查看原因。

常见问题
--------
* 双击没有反应？请先安装 .NET 10 Desktop Runtime：
  https://dotnet.microsoft.com/download/dotnet/10.0
* 如何完全退出？右键托盘图标 → Exit。
